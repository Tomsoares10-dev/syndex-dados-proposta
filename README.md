# Dados da Proposta — Syndex

Formulário para o comercial enviar à Diretoria os dados de propostas de desembaraço (Importação/Exportação). Tudo em maiúsculas, CNPJ/CEP com preenchimento automático e botões de copiar.

Os dados digitados ficam só no navegador do aparelho (localStorage); nada é enviado a servidor.
Atualizado em 26/10/2026.
